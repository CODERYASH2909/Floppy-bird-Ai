How the AI thinks

Every frame it looks at 4 numbers:

  • bird height
  • vertical speed
  • distance to next pipe
  • height of the gap

It multiplies them by learned weights — if the sum is positive, it flaps. A genetic algorithm breeds the best-scoring birds each generation, so the weights slowly get better.
